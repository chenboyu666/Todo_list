# Todo list

`Todo list` 是一款 Windows 桌面待办与时间管理工具。它可以悬浮在桌面上，帮助你把当前任务、工作计时、截止倒计时、提醒状态和历史洞察保持在视野里。

## 下载与运行

推荐下载 Windows 发布版：

[下载 Todo-list-V1.1-windows.zip](https://github.com/chenboyu666/Todo_list/releases/download/v1.1/Todo-list-V1.1-windows.zip)

下载后完整解压 ZIP，进入 `Todo-list-V1.1-windows` 文件夹，双击 `Todo list.exe` 即可运行。请保留 `_internal` 文件夹，不要单独移动 exe。

首次启动时，程序会在 exe 同级目录自动创建 `data` 文件夹，用来保存任务、设置、历史记录、背景图片和自定义图标等数据。

## V1.1 更新

- 新增分辨率适配设置：可在设置中选择大分辨率、中分辨率、小分辨率三档界面尺寸。
- 默认启动改为中分辨率，适合笔记本屏幕；高分辨率显示器可切换到大分辨率，小屏幕可切换到小分辨率。
- 优化中分辨率下的最小窗口尺寸，避免任务卡片和顶部信息挤压重叠。

## 主要功能

- 桌面悬浮窗口：无边框界面，支持拖动、缩放、置顶、托盘恢复和鼠标穿透。
- 实时时间面板：显示数字时钟，并统计今日完成、进行中、临近截止和超时任务。
- 多任务管理：支持新增、编辑、删除、完成、暂停、继续和置顶当前任务。
- 优先级管理：任务可设置高、中、低优先级，并通过图标、颜色和卡片状态区分。
- 工作计时与截止倒计时：同时展示实际工作计时和截止剩余时间。
- 任务提醒：临近截止、超时和完成任务时会出现提醒小窗。
- 外观设置：支持透明度、分辨率适配、背景图片、随机背景文件夹和程序图标设置。
- 历史任务：查看已完成任务，可按日期、优先级、状态、标签和任务名称筛选。
- 历史统计：查看优先级结构、完成趋势、准时/超时分布和标签统计。
- 3D 洞察图：根据已完成任务的标题和标签提取关键词，生成类似 Obsidian 的任务关系图。
- CSV 导出：可按日期范围导出历史任务数据。

## 基础使用

1. 进入发布文件夹，双击 `Todo list.exe` 启动程序。
2. 点击新增任务，填写任务名称、优先级、预估工作量、截止时间和备注。
3. 在任务列表中选择任务，可将其设为当前任务。
4. 当前任务区域会显示工作计时、截止倒计时、完成和删除等常用操作。
5. 点击历史任务，可查看完成记录、统计图表、3D 洞察图和 CSV 导出。
6. 点击设置，可调整提醒、外观、背景、图标、托盘和窗口行为。

## 从源码打包

开发者可以使用项目内置脚本生成 Windows 便携版：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1
```

打包完成后，程序位于：

```text
dist\Todo list\Todo list.exe
```

## 数据保存

便携版文件夹结构如下：

```text
Todo list.exe
_internal\
data\
```

程序会在 exe 同级目录创建 `data` 文件夹。这里保存任务、设置、历史记录和自定义资源。移动程序时，请整体移动便携文件夹。

## 注意事项

- 程序适用于 Windows 系统。
- 如果系统提示未知发布者，请确认文件来自可信来源后再运行。
- 关闭窗口后，程序可能会按设置最小化到托盘；可从托盘图标恢复或退出。
